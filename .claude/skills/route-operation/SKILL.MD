## When to use
When asked to update or delete existing route, create new route.

## Instructions
1. Before updating express route code read docs/api.md and understand the contract that routes following.
2. Implement express route code change based on contract.
3. After express route code change, update docs/api.md with information about route that was changed/created/deleted in the same pattern as docs/api.md.
