# Add API Route

Use this skill when working on API routes in this repository.

## What to do
- Follow the existing Express style in the project.
- Reuse the repo's current route patterns and file structure.
- Keep response shape consistent with the existing API.
- Add or update tests if the route behavior changes.
- Avoid changing unrelated code.

## Checklist
- Identify the closest existing route as a reference.
- Match naming, request handling, and error handling style.
- Keep the implementation minimal and consistent.
- Update tests for success and failure cases when relevant.
