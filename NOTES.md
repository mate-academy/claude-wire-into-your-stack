## MCP-сервер

Підключено mcp-server-fetch. Вибір був зроблений за принципом економії та мінімальної складності для виконання навчального завдання. У `.claude/settings.json` дозволено лише інструмент `mcp__fetch__fetch`.

## Skill

Створено create-express-route. Skill описує створення Express route відповідно до структури та conventions цього проєкту. Description сформульовано так, щоб skill спрацьовував на запити про створення Express route, endpoint або resource в цьому проєкті.

## Custom command

Створено /summarize-changes. Команда коротко описує поточні незакомічені зміни в репозиторії. Її зроблено без аргументів, оскільки для виконання цього навчального завдання потрібен максимально простий і дешевий shortcut.

## Hook

Налаштовано "PostToolUse" hook з matcher "Edit|Write". Він реагує на редагування або створення файлу - запускає `git diff --check`.

## Headless-запуск

Завдання: "прочитати `package.json` і визначити значення поля `name`". Дозволено лише інструмент `Read`.
