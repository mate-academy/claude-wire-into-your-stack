# NOTES

**MCP server.** Connected `docs`, the `@modelcontextprotocol/server-filesystem` server scoped to `./docs`, at project scope via `.mcp.json` — credential-free, and useful because it lets Claude pull up `docs/api.md` (the route/status-code/error-shape reference) while working on `routes/` without guessing at the contract. The permission rule in `.claude/settings.json` allows only the read-only tools — `read_file`, `read_multiple_files`, `list_directory`, `directory_tree`, `search_files`, `get_file_info`, `list_allowed_directories` — leaving `write_file`, `edit_file`, `move_file`, and `create_directory` off the allowlist so the server can be consulted but not used to edit docs unattended.

**Skill.** `add-resource-route` captures the repeated shape of adding a new resource to this API: a store helper in `db/store.js`, a route file in `routes/` with the standard `GET`/`GET :id`/`POST`/`PUT` handlers and 400/404/`{ "error": "message" }` responses, a mount line in `server.js`, and a matching `node:test` + `supertest` file. The description names concrete trigger phrases ("add/create a new resource, endpoint, or route", with examples like "add a products resource") and an explicit negative ("not for editing an existing route's behavior, unrelated bug fixes, or frontend work") so it fires on new-resource requests and stays quiet on everything else.

**Command.** `/review-route <file>` checks a given route file against the four CLAUDE.md conventions (one file per resource, all data through the store, 400/404 status codes, `{ "error": "message" }` shape) and reports deviations or confirms compliance. It's worth a shortcut because it's a check I'd otherwise redo by hand for every new or edited route, and it takes one argument (`$1`) so it's a one-liner to invoke.

**Hook.** A `PreToolUse` hook on the `Bash` matcher — it prevents rather than reacts. It inspects `tool_input.command` and denies anything matching `rm -rf`, `--force`, or `git reset --hard` with a clear reason, before the command ever runs.

**Headless run.** Ran `/review-route routes/health.js` via `claude -p` with `--allowedTools "Read"` — the only capability that command needs, since it only reads a file and reports findings, never edits or shells out. Everything else (Edit, Write, Bash, the `docs` MCP tools) was left off, so the unattended run had no more reach than the task required.
